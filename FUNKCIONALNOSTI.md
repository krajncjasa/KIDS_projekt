# Seznam funkcionalnosti

## Uvod

Dokument predstavlja seznam funkcionalnosti informacijskega
sistema podjetja TechSolutions. Namen sistema je uporabnikom
omogočiti enostaven dostop do storitev podjetja, upravljanje
uporabniških računov in oddajo zahtevkov.

## Funkcionalnosti sistema

| ID | Ime | Opis | Prioriteta |
|---|---|---|---|
| F01 | Registracija | Uporabnik lahko ustvari nov uporabniški račun. | Visoka |
| F02 | Prijava | Uporabnik se lahko prijavi v svoj račun. | Visoka |
| F03 | Odjava | Uporabnik se lahko varno odjavi iz sistema. | Visoka |
| F04 | Urejanje profila | Uporabnik lahko spreminja svoje osebne podatke. | Srednja |
| F05 | Pregled storitev | Uporabnik lahko pregleda vse storitve podjetja. | Visoka |
| F06 | Iskanje storitev | Uporabnik lahko išče storitve po ključnih besedah. | Srednja |
| F07 | Oddaja naročila | Uporabnik lahko odda naročilo za izbrano storitev. | Visoka |
| F08 | Pregled naročil | Uporabnik lahko spremlja stanje svojih naročil. | Visoka |
| F09 | Kontaktni obrazec | Uporabnik lahko podjetju pošlje vprašanje. | Srednja |
| F10 | Ponastavitev gesla | Uporabnik lahko ponastavi pozabljeno geslo. | Visoka |
| F11 | Obvestila | Uporabnik lahko prejema obvestila o svojih naročilih. | Srednja |
| F12 | Ocenjevanje storitev | Uporabnik lahko oceni opravljeno storitev. | Nizka |

## Razlaga prioritet

- **Visoka:** Funkcionalnost je nujna za delovanje sistema.
- **Srednja:** Funkcionalnost izboljšuje uporabniško izkušnjo.
- **Nizka:** Dodatna funkcionalnost, ki ni nujna za delovanje.
